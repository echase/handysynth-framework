## What a concern is

A cross-cutting fix or standard that *could* apply to more than one variant — captured at fix-time, while
the reasoning is hot, so it can be propagated with judgment instead of re-derived from a diff later.

The 14 items in [VARIANT-POLISH.md](../VARIANT-POLISH.md) are the seed concerns. VARIANT-POLISH stays the
human-readable "what good looks like" standard; concern files add the machine-trackable rollout state.

## File format

One file per concern, named `<id>.md`. Frontmatter is the source of truth; the body holds the recipe and
any per-variant deferral reasoning.

```markdown
---
id: motion-smoothing-ema
intent: Per-axis EMA on landmarks before mapping to audio
why: Raw MediaPipe landmarks jitter ±2–5px; without smoothing pitch/volume flutter audibly
acceptance: Steady pinch in one position → stable tone, no audible warble (human judgment)
detection: Search for PITCH_SMOOTH_K / smoothedPx accumulation in the draw loop
applicability: N-A where there is no continuous pitch/volume axis (e.g. drumspace)
status:
  air-guitar: applied@v1
  augury: applied@v2
  drumspace: n/a
  syrinx: unknown
---

## Recipe

### class-expanded
...per-architecture edit...

### class-minified
...minified-anchor variant...

### flat-module
...standalone variant...

## Deferrals
- **drift** — deferred 2026-06-03: theme rework in flight; revisit-trigger: after drift v3 lands.
```

## Status values

| Value | Meaning |
|-------|---------|
| `applied@<ver>` | Present and verified in this variant at that version |
| `deferred` | Consciously skipped; reason + revisit-trigger in the body |
| `n/a` | Genuinely doesn't apply (per `applicability`) |
| `needs-patch` | Applies, not yet present — open work |
| `unknown` | Not yet classified by a sweep |

## How it's used

- **Push (fix-time):** make a fix → write/append the concern file → run the sweep across variants.
- **Pull (work-start):** before touching a variant, check its column in [STATUS.md](STATUS.md) — address or
  re-defer any open rows.
- **Re-verifiability:** the sweep reads the actual variant files and validates these status maps.
  "Frontmatter says applied, file disagrees" is a finding, not blind truth.

`STATUS.md` is a **generated rollup** — regenerated by the sweep, never hand-edited.
